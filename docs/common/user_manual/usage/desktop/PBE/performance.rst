PRF: Recovery Performance Assessment
====================================

The performance assessment panel defines the inputs to set up
a functional recovery assessment for a building. PBE currently
supports two methodologies for estimating post-earthquake recovery --
click the corresponding entry below for the input details.

If you do not want to perform a functional recovery simulation, set
the **PRF Application** dropdown to ``None``.
